# 健身房预约（复刻版 · 纯前端演示）

把钉钉里那个「健身房预约」页按 1:1 复刻成了一个网页应用，布局、配色、胶囊、日期条、卡片间距都照真机截图还原。

> ⚠️ 纯本地演示：所有数据存在浏览器 `localStorage`，**没有后端、不连钉钉、不会产生真实预约**，
> 也扫不了码签到。它的用途是界面复刻练习 / 做原型 / 演示，不能拿去当真实预约凭证。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 全部结构 + 样式 + 逻辑（单文件，无依赖） |
| `banner.png` | 顶部横幅插画（从截图裁的素材） |
| `icon-512.png` | 添加到桌面的图标 |
| `manifest.webmanifest` | PWA 清单，可「添加到主屏幕」以独立窗口运行 |

## 运行

```bash
cd gym-app
python3 -m http.server 8765 --bind 127.0.0.1
```

手机浏览器打开 `http://127.0.0.1:8765/index.html`（容器和手机共用回环地址）。
也可以在电脑上直接双击 `index.html`。

想让它像 App 一样全屏：浏览器菜单 →「添加到主屏幕」，用 `manifest` 里声明的 standalone 模式打开。

## 已实现

- **顶栏**：返回、标题、下拉箭头、更多（黑色沉浸）
- **横幅**：原图插画
- **两个标签页**：健身房预约 / 我的预约，蓝色下划线
- **日期条**：今天起 7 天，选中态蓝底白字
- **场次卡片**：黄点 + 场次名 + 状态胶囊（未预约/已预约）、时间段 + 蓝色箭头、浅蓝条（健身房 / 剩余：N / 操作胶囊）
- **状态机**（当前规则：剩余恒显示 0，但一直可约）：
  - `未约` → 灰色【预约】，可点
  - `已约` → 蓝色【已预约】+ 红色【取消预约】
  - 不再有【人数已满】禁用态；预约/取消都不改剩余数（保持 0）
- **我的预约**：按日期排序列出所有已约场次，支持就地取消
- **反馈**：底部 Toast（预约成功 / 已取消预约 / 该场次已满）
- **持久化**：刷新不丢；清空 `localStorage` 即恢复初始演示数据

## 怎么打开

**本机（手机自己）**
```bash
cd gym-app && python3 -m http.server 8765 --bind 0.0.0.0
```
浏览器打开 `http://127.0.0.1:8765/index.html`

**同一个 Wi-Fi 下的其它设备**
用手机的局域网 IP：`http://10.120.1.133:8765/index.html`
（手机 IP 会变，安卓在「设置 → WLAN → 当前网络」里能看到）

## 怎么发给别人

**方式一：直接把文件夹发过去（最简单，离线可用）**
把 `gym-app` 整个文件夹（或 `gym-app.zip`，约 435 KB）发给对方，
解压后双击 `index.html` 就能看。注意必须是**整个文件夹**，`index.html` 依赖同目录的 `banner.png`。

**方式二：给一个公网链接（对方点开就能看）**
把本地服务暴露到公网，临时用 Cloudflare 免费隧道：
```bash
/tmp/cloudflared tunnel --url http://127.0.0.1:8765 --no-autoupdate --metrics 127.0.0.1:39233
```
启动后终端会打印一个 `https://xxx.trycloudflare.com` 的地址，直接发人。
- ⚠️ 每次重启地址都会变，且没有可用性保证，适合临时演示
- 手机锁屏/进程被杀隧道就断

**方式三：长期托管（推荐，地址固定）**
把 `index.html` + `banner.png` + `icon-512.png` + `manifest.webmanifest` 四个文件上传到任意静态托管：
- **Netlify Drop**（netlify.com/drop）：把文件夹拖进去，10 秒出网址，不用注册也能试
- **Cloudflare Pages** / **Vercel**：连 GitHub 仓库自动部署
- **GitHub Pages** / **Gitee Pages**：适合长期放开源项目

注意：接收方用**浏览器**打开，微信/QQ 内置浏览器有时会拦截或强制深色模式。

## 单文件模式（file:// 直接打开）

`index.html` 已经把横幅图**内嵌成 base64 data URI**，所以：

- 直接双击 / 用文件管理器打开 `index.html`，横幅也能正常显示，不依赖同目录的 `banner.png`
- 只有一个 81 KB 的 html 文件时，拷到任何设备都能看
- 用 `file://` 打开时，脚本会自动去掉 `manifest` 和 `apple-touch-icon` 的引用，避免 404
- `localStorage` 在 `file://` 下可能被浏览器禁用，代码里已 try/catch，最坏情况是刷新后回到初始数据

`banner.png` / `icon-512.png` / `manifest.webmanifest` 现在只在**用 http 托管**时才需要（PWA 添加到主屏幕）。

## 日期条规则

一周固定从**周一**排到**周日**，位置永远不变：

- 今天只是被高亮（蓝色选中）的那一格，显示为「今天」，不会因为今天周几就整条往前挪
- 已经过去的日期（比如今天周二，那周一）第三行**留空**，不写「可约」也不写「已过」，只是没有状态字；点进去三场都是「人数已满」
- `load()` 里做了跨周校验：一旦存储的周次和当前周对不上（比如过了一周再打开），自动重新生成，不会留着上周的数据
